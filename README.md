# ⏱️ Timer+ (TimerPlus 모바일 운동 타이머 PWA)

아이폰(iOS)과 안드로이드에서 널리 사용되는 고성능 운동 타이머 어플리케이션 **"TimerPlus"**의 핵심 기능에 **웨이트 세트 카운터**, **홈트 서킷 종목 안내**, **1초 초침(똑-딱) 사운드**, **가로 모드 대형 전광판 뷰**를 더한 **PWA(Progressive Web App)** 프로젝트입니다.

네트워크 연결이 없는 헬스장, 지하, 비행기 모드에서도 **100% 오프라인**으로 작동하며, 스마트폰 홈 화면에 추가하여 네이티브 앱처럼 사용할 수 있습니다.

---

## ✨ 4대 핵심 운동 모드 (하단 탭 메뉴)

### 1. ⏱️ 인터벌 · 타바타 · 홈트 서킷 모드 (Interval & Circuit)
- **타바타 (Tabata)**: 20초 운동 / 10초 휴식 8라운드 (총 4분)
- **홈트 전신 서킷 & HIIT**: 다중 세트, 세트 간 휴식, 마무리 쿨다운(Cooldown) 지원
- **라운드별 운동 종목 설정**: 라운드마다 운동 이름(예: `스쿼트`, `푸쉬업`, `런지`, `플랭크`) 입력 시 다음 동작 미리보기 및 한국어 음성 안내(`"휴식. 다음 동작, 플랭크"`) 지원
- **실시간 시간 연장/단축**: 운동·휴식 중 원터치 `-10초` / `+15초 연장` / `+30초` 퀵 버튼 제공
- **루틴 복제 & 길게 눌러 시간 조절**: 기본 루틴 복사본 생성 및 `+`/`-` 길게 누르기 고속 증감 지원

### 2. 🏋️ 웨이트 세트 & 자유 휴식 모드 (Weight Training)
- **세트 망각 방지 트래커**: 현재 몇 세트째인지 직관적인 진행 배지(`✓ 1`, `✓ 2`, `● 3`, `4`) 및 목표 세트 실시간 조절
- **원터치 휴식 시작**: 세트 종료 직후 버튼 한 번으로 설정된 휴식 시간(`45초` / `1분` / `1분 30초` / `2분` / `3분`) 즉시 카운트다운
- **세트 수행 시간(TUT) 측정**: 필요 시 세트 수행 시간 카운트업 측정 및 휴식 중 `-15초` / `+15초` / `+30초` / `스킵` 즉시 조작
- **운동 종목 메모**: `벤치프레스`, `스쿼트` 등 현재 수행 중인 종목 빠른 메모 지원

### 3. 🥊 복싱 & 격투기 라운드 모드 (Rounds)
- **프로 복싱 (3분 × 12R)**, **복싱 (3분 × 5R)**, **MMA (5분 × 5R)**, **섀도우 복싱 (2분 × 5R)**
- 실제 경기장 공 소리(Boxing Bell) 및 라운드 종료 10초 전 나무 타격음(Wood Clapper) 알림

### 4. ⏱️ 정밀 스톱워치 모드 (Stopwatch)
- **1/100초(밀리초) 정밀 계측**, 구간 기록(Lap Time) & 최고/최저 랩 자동 하이라이트

## 🔥 운동 특화 스마트 기능

- **⏱️ 1초 똑딱(Tick-Tock) 초침 사운드**: 화면을 보지 않고 운동해도 매 1초마다 가벼운 기계식 초침 소리로 시간이 정상적으로 흐르고 있음을 인지 가능 (설정에서 ON/OFF 가능)
- **🔔 절반 경과 & 마지막 라운드 알림**: 30초 이상 운동 시 절반 지점 알림 및 마지막 라운드 파이팅 음성 큐 제공
- **📺 가로 모드(Landscape) 2단 대형 전광판 뷰**: 스마트폰을 가로로 세워두면 좌측 대형 다이얼 + 우측 컨트롤의 체육관 전광판 레이아웃으로 자동 전환
- **🎵 음악 앱 동시 재생**: 유튜브 뮤직, 스포티파이 등 배경 음악을 끊지 않고 타이머 사운드 믹싱 재생 (`효과음+음성` / `효과음만` / `음성만` / `무음` 4단계 지원)
- **🛡️ 오터치 리셋 방지**: 운동 진행 중 실수로 리셋 버튼을 스쳐도 바로 초기화되지 않도록 2회 터치 확인 보호 적용
- **🎧 블루투스 이어폰 연동 & ⌨️ 키보드 단축키 (`Space`, `←/→`, `+/-`, `R`, `M`, `1~4`)**
- **💡 화면 꺼짐 방지 (Screen Wake Lock API)** & **100% 오프라인 캐싱 (`sw.js`)**
